# Support Resources

Welcome to the Homonoid Design System support portal. Whether you are building accessible user interfaces with our React package, integrating semantic tokens, or exploring spatial continuity principles, our resources and community are here to assist you.

<br>

### Documentation and Showcase
<br>

The primary destination for technical guidance, component demonstrations, and token specifications is our online portal.

1. Design Portal: Explore complete architectural documentation and live interactive previews at homonoid.io.

2. Component Explorer: Inspect component properties, dimensional stability behaviors, and source code within the showcase application.

3. Token Specifications: Review semantic Chroma color scales, typography definitions, spatial dimensions, and standardized easing curves in the tokens documentation.

<br>

### Community Discussions
<br>

Connect with fellow engineers and system maintainers through our official community forums on GitHub Discussions.

1. Questions and Answers: Inquire about component usage patterns, integration strategies, or best practices for multiplatform layouts.

2. Ideas and RFCs: Propose concepts for new components, discuss layout stability paradigms, or share architectural feedback.

3. Show and Tell: Share digital applications, custom themes, or showcase implementations built upon Homonoid foundations.

<br>

### Issue Tracking
<br>

When encountering unexpected behavior, bugs, or defects within our packages, please file a structured report in the appropriate repository issue tracker.

1. Bug Reports: Utilize the bug report issue template to provide environment specifications, reproduction code, and descriptions of layout discrepancies.

2. Feature Proposals: Utilize the feature proposal issue template to request new component patterns or token extensions aligned with our core architectural pillars.

<br>

### Direct Contact
<br>

For organizational adoption, security concerns, or sensitive inquiries not suitable for public forums, reach out directly to our team at support@homonoid.io.
